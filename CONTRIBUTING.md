## Contributing to System Design Journey

Welcome to the System Design Journey repository. We appreciate your interest in improving this learning resource for system design topics and interview preparation.

This repository is a collection of topic-based notes, examples, and study material for the Season 1 system design playlist. Contributions should stay focused, easy to follow, and aligned with the project structure.

## Repository Overview

This is not an application repository and there is no root build or test command.

Key repository conventions:

- Each major topic lives in its own folder under `season-1/`.
- Topic folders follow the naming pattern `season-1/<number>.<topic-name>/`.
- Keep all work related to one topic inside that specific folder.
- Do not edit files in other topics unless the change is explicitly required for the task.
- `Codes/`, `Repos/`, `Tasks/`, `Designs/`, and `Notes/` are not part of this repository and should not be assumed to exist.
